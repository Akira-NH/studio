# **App Name**: Hotel Imperial

## Core Features:

- Firebase Authentication: Enable staff login and registration using Firebase Authentication.
- Dashboard Overview: Display key metrics such as current occupancy, total bookings, and revenue using charts and summary cards.
- Rooms Management (CRUD): Allow staff to add, edit, delete, and view room details (number, type, price, availability).
- Bookings Management: Form and table for managing reservations, including check-in/out dates and assigned rooms. Uses Firestore real-time updates for room availability.
- Guests Management: Maintain a list of guests with contact information and booking history.
- Payments Management: Track and display payment records, with options to mark invoices as paid/unpaid.
- AI-Powered Booking Insights: Use AI to analyze booking patterns and suggest optimal pricing and availability adjustments; acts as a tool to provide suggestions for improving occupancy rates.

## Style Guidelines:

- Primary color: Deep sapphire blue (#0E62B8) to convey trust and professionalism.
- Background color: Soft, desaturated blue-gray (#E8F0FE) for a calm, neutral backdrop.
- Accent color: Vibrant coral (#FF7F50) to highlight interactive elements and important actions.
- Body and headline font: 'Inter', a sans-serif font, provides a modern and readable experience.
- Use minimalist and consistent icons from Material UI's icon set.
- Implement a responsive design with a clean dashboard layout featuring a sidebar navigation and top navbar.
- Subtle transition animations for page navigation and data updates to enhance user experience.
